# OpenCode 上下文分析技能

此技能专门用于深度分析 OpenCode 项目的上下文选择机制，包括以下核心方面：

## 分析范围

1. **动态上下文分析** - 是否支持动态上下文管理
2. **选择时机分析** - 上下文选择的触发时机和条件
3. **机制实现分析** - 上下文选择的具体技术实现
4. **上下文类别分析** - 不同上下文类型的分类和选择策略

## 使用方法

当需要分析 OpenCode 的上下文管理机制时，调用此技能将自动执行以下步骤：
- 搜索相关代码文件
- 分析核心算法实现
- 提取关键设计模式
- 生成技术分析文档

## 输出格式

技能将生成结构化的技术分析文档，包含代码引用、算法说明和设计原理分析。
