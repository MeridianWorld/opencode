## 快速开始

### 1. 启动服务

确保后端服务和前端都已启动：

```powershell
# 终端 1 - 后端服务
cd packages/opencode
bun run --conditions=browser ./src/index.ts serve --port 4096

# 终端 2 - 前端界面（已启动）
cd webapp-previewer
bun run dev
```

前端访问地址：http://localhost:3000

### 2. 自动预览功能

#### 场景一：已有的 HTML 文件

当您打开一个包含 HTML 文件的项目时：

1. 访问 http://localhost:3000
2. 选择包含 HTML 文件的项目目录
3. 预览面板会**自动打开**（如果自动预览已启用）
4. 显示检测到的第一个 HTML 文件

**支持的常见 HTML 文件名**：
- `index.html`
- `app.html`
- `main.html`
- `public/index.html`
- `dist/index.html`
- `build/index.html`
- `src/index.html`

#### 场景二：新生成的 HTML 文件

当 OpenCode 生成新的 HTML 文件时：

1. 在会话中请求生成 HTML 页面
2. OpenCode 创建 HTML 文件
3. 预览面板**自动打开**并显示新生成的文件
4. 文件状态标记为"active"（活跃）

### 3. 手动控制

#### 打开预览面板

**方法 1**：点击右下角的浮动按钮
- 蓝色 "Preview" 按钮
- 位置：屏幕右下角
- 只在预览面板关闭时显示

**方法 2**：使用命令面板（待实现）
- 按 `Ctrl/Cmd + K`
- 输入 "Open Preview"

#### 关闭预览面板

点击预览面板右上角的 **X** 按钮

#### 切换设备模式

预览面板顶部提供三种设备模式：

| 模式 | 宽度 | 用途 |
|------|------|------|
| 🖥️ Desktop | 100% | 桌面浏览器视图 |
| 📱 Tablet | 768px | 平板设备视图 |
| 📱 Mobile | 375px | 手机设备视图 |

#### 自动预览开关

点击 **"Auto"** 按钮：
- **启用**（蓝色背景 + 勾选）：检测到 HTML 文件时自动打开预览
- **禁用**（灰色背景）：需要手动打开预览面板

#### 在新标签页打开

点击外部链接图标 🔗，在新浏览器标签页中打开预览

## 使用示例

### 示例 1：预览已有的 HTML 项目

1. 打开 http://localhost:3000
2. 点击 "New Session"
3. 选择包含 `index.html` 的项目目录
4. 预览面板自动打开，显示 `index.html`

### 示例 2：生成并预览新的 HTML 页面

1. 在会话中输入：
   ```
   创建一个简单的个人主页 HTML 文件
   ```
2. OpenCode 生成 `index.html`
3. 预览面板自动打开
4. 查看生成的页面效果

### 示例 3：测试响应式设计

1. 打开预览面板
2. 点击 "Desktop" 查看桌面视图
3. 点击 "Tablet" 查看平板视图
4. 点击 "Mobile" 查看手机视图
5. 检查页面在不同设备上的显示效果

### 示例 4：手动控制预览

1. 关闭自动预览（点击 "Auto" 按钮）
2. 预览面板关闭，显示浮动按钮
3. 需要预览时，点击浮动按钮
4. 预览面板重新打开

## 故障排除

### 问题 1：预览面板没有自动打开

**可能原因**：
- 自动预览功能被禁用
- 项目目录中没有 HTML 文件
- 后端服务未启动

**解决方法**：
1. 检查 "Auto" 按钮是否启用（蓝色背景）
2. 确认项目目录中存在 HTML 文件
3. 确保后端服务运行在 http://localhost:4096
4. 点击浮动按钮手动打开预览

### 问题 2：预览显示空白

**可能原因**：
- HTML 文件路径不正确
- 后端 `/view/` 接口无法访问
- HTML 文件内容为空

**解决方法**：
1. 检查控制台是否有错误信息
2. 尝试在新标签页中打开预览
3. 确认 HTML 文件存在且有内容
4. 检查后端服务日志

### 问题 3：检测不到 HTML 文件

**可能原因**：
- 文件名不在常见模式中
- 文件路径包含特殊字符
- SDK 状态未正确加载

**解决方法**：
1. 将文件重命名为常见名称（如 `index.html`）
2. 检查文件路径是否包含特殊字符
3. 刷新页面重新加载
4. 查看浏览器控制台日志

### 问题 4：设备模式切换无效

**可能原因**：
- CSS 样式覆盖
- 页面布局限制

**解决方法**：
1. 刷新页面
2. 检查浏览器控制台错误
3. 尝试调整浏览器窗口大小
